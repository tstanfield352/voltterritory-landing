# VoltTerritory Landing

The public "coming soon" page for www.voltterritory.com. Kept separate from
the VoltTerritory dashboard until the full site is ready.

## Layout

- `public/` — the page itself (plain HTML, no build step)

## Deploy

Cloudflare Pages project `voltterritory-landing` (build command: none, output
directory: `public`). Every push to `main` goes live automatically on
voltterritory.com and www.voltterritory.com.
